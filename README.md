# english-pbl-2026
Site for Emily's english PBL project for 2026

## GitHub Pages

After deployment, the site will be available at
<https://andrei-petrescu.github.io/english-pbl-2026/>.
Before the first deployment, enable Pages in the repository settings: open
**Pages** and select **GitHub Actions** as the build and deployment source.
After that, pushes to `main` deploy the site automatically. You can also start
a deployment from the **Actions** tab.

This repository is public, including its source and history. Do not commit
private or identifying student information.
